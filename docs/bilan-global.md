### Bilan Global du projet en intelligence artificielle pour développeur: 

## Ce que l'on a apprécié: 

- La découverte de mécanisme tel que les harnets et les senseurs
- La découverte du fonctionnement d'un agent IA qui se focalise sur le code

## Ce que l'on a pas apprécié: 

- Le fait de devoir faire l'entièreté d'un projet 100% avec l'ia et juste devoir review du code était par moment très ennuyant.
- Un ressenti qui est partagé sur le long du projet c'est que le métier de "vibe coder" est vraiment ennuyant. 


## Ce que l'on a remarqué ou appris: 

- Vibe coder sans avoir de connaissances au préalable c'est vraiment une erreur, même avec de bonnes connaissances ça demande beaucoup de discpline pour discerner les bugs, les failles de sécurités et les mauvaises pratiques de l'agent. 

## Ressenti global: 

Dans l'ensemble le projet était intéressant mais dans le cadre de l'intérêt de notre cursus nous n'avons pas spécialement apprécié celui-ci, bien qu'il nous arrive souvent d'utuliser l'ia pour nous aider, c'est rarement pour lui faire générer tout un bloc de code (hors test qui est une exception..).
